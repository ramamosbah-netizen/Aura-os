baseline and records the final local closure evidence. Provider-confirmed
delivery remains external evidence and is not fabricated.

## Closure status

Implemented and tested: Contract revisions, negotiation, client shares through
prepared/dispatched states, bounded approval decision records with access/matrix
hooks, amendments, closeout commands, DMS association entrypoint,
parent-integrity foreign keys, and tenant RLS. Migration 0281 adds the durable
approval decision store; migrations 0276–0280 remain unchanged.

The final local run proved the authenticated Contract 360 workflows for
negotiation resolution, canonical revision approval with author/approver
segregation, signing/freeze, client-share preparation/dispatch, DMS association
and amendment review/approval/signing. A newly-created local Contract was
signed by a different actor, created its Project, completed through the
governed Closeout command, and remained `completed` after reload.

The C4/C5 PostgreSQL Vitest specs were executed in a disposable runner on the
private Docker network using the application role for governed writes and the
configured migration role for read-only evidence: 2 files and 3 tests passed.
Real API/Database race proofs also passed: concurrent revision creation yielded
unique revisions 1/2, concurrent amendment creation yielded unique amendments
1/2, client-share dispatch produced one dispatched record (201/403), approval
submission produced one pending approval (201/403), signing replay produced one
signed consequence (200/403), and concurrent terminal closeout replay remained
completed with one canonical completion event. Contract-specific audit/event
rows were read back; the approval table has a tenant/target unique constraint
and FORCE RLS. Parent-contract validation is enforced on approval routes and
approval self-checks occur before persistence.

One bounded UI defect found by the closeout proof was corrected: the Closeout
button now calls the existing POST command instead of sending PATCH. No new
domain authority or migration was introduced by this fix. No provider-confirmed
email delivery was attempted. A second bounded evidence defect was corrected in
the Contracts status controller: domain authorization/approval denials now pass
through the global taxonomy as HTTP 403 instead of being wrapped as HTTP 400;
the full four-case SoD regression then passed.

No Sales/Commercial or Project Delivery authority was changed. No shared
Supabase data was mutated, no migration was rewritten, and no Procurement work
was started.
