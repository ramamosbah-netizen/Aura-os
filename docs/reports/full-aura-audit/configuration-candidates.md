# Configuration candidates

Owner, 2026-09-28: AURA is JEET-first but multi-company-ready. Every hardcoded business rule found while closing a gap is logged here and classified — platform invariant, company policy, workflow, permission, evidence requirement or system configuration. A platform invariant is listed so that it is NOT made configurable. Nothing here is built yet; this is the Admin Center's requirements, collected on the way. UX-01 found no hardcoded business rule.
